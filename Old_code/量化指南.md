# ResNet-18 量化处理指南

## 什么是模型量化？

模型量化是将模型的参数和计算从 **32位浮点数（FP32）** 转换为 **8位整数（INT8）** 的过程。

### 量化的好处
- 📦 **模型大小减少 75%**（32位 → 8位）
- ⚡ **推理速度提升 2-4倍**（在支持的 CPU 上）
- 💾 **内存占用降低**
- 🎯 **准确率下降通常 < 1%**

---

## PyTorch 支持的三种量化方法

### 1. 动态量化（Dynamic Quantization）
- **特点**：仅量化权重，激活值在推理时动态量化
- **优点**：实现最简单，无需校准数据
- **缺点**：对 CNN 效果有限，更适合 RNN/LSTM
- **准确率损失**：1-2%

```python
import torch.quantization as quant
quantized_model = quant.quantize_dynamic(
    model, 
    {nn.Linear}, 
    dtype=torch.qint8
)
```

---

### 2. 静态量化（Static Quantization）⭐ 推荐
- **特点**：同时量化权重和激活值
- **优点**：CNN 效果最好，速度快
- **缺点**：需要校准数据集
- **准确率损失**：0.5-1%

**流程：**
```
配置 → 准备 → 校准 → 转换
```

---

### 3. 量化感知训练（QAT - Quantization Aware Training）
- **特点**：训练时模拟量化效果
- **优点**：准确率损失最小
- **缺点**：训练时间长
- **准确率损失**：< 0.5%

---

## ResNet-18 静态量化完整流程

### 步骤 1: 准备模型

```python
import torch
import torch.quantization as quant
from Resnet4CIFAR100 import resnet18

# 加载模型
model = resnet18(num_classes=100, img_size=32)
model.eval()  # 切换到评估模式

# 可选：加载预训练权重
model.load_state_dict(torch.load('resnet18_cifar100.pth'))
```

### 步骤 2: 配置量化

```python
# 设置量化配置（x86 CPU 使用 'fbgemm'）
model.qconfig = quant.get_default_qconfig('fbgemm')

# 准备模型：插入观察器（Observer）
model = quant.prepare(model, inplace=False)
```

**量化配置说明：**
- `'fbgemm'`: Intel/AMD x86 CPU
- `'qnnpack'`: ARM CPU（移动设备）

### 步骤 3: 校准模型（关键步骤）

校准是静态量化的核心，通过运行代表性数据来收集激活值的统计信息。

```python
def calibrate(model, data_loader, num_batches=100):
    model.eval()
    
    with torch.no_grad():
        for i, (images, _) in enumerate(data_loader):
            if i >= num_batches:
                break
            
            # 前向传播，观察器自动收集统计信息
            model(images)
    
    return model

# 执行校准
model = calibrate(model, calibration_loader, num_batches=100)
```

**校准要点：**
- ✅ 使用训练集或验证集的子集
- ✅ 100-200 个批次通常足够
- ✅ 数据要有代表性（覆盖各种输入场景）
- ❌ 不需要所有数据

### 步骤 4: 转换为量化模型

```python
# 将 FP32 模型转换为 INT8 模型
quantized_model = quant.convert(model, inplace=False)

# 保存量化模型
torch.save(quantized_model, 'resnet18_quantized.pth')
```

### 步骤 5: 使用量化模型

```python
# 加载量化模型
quantized_model = torch.load('resnet18_quantized.pth')
quantized_model.eval()

# 推理（仅支持 CPU）
with torch.no_grad():
    output = quantized_model(input_tensor)
```

⚠️ **注意**：量化模型只能在 **CPU** 上运行，不支持 GPU！

## 观察器（Observer）详解

观察器是量化的核心组件，负责收集数据统计信息并计算量化参数。

### 观察器的作用

在 `ResnetQuanti.py` 中的示例展示了观察器的工作原理：

```python
observers = [MinMaxObserver(), MovingAverageMinMaxObserver(), HistogramObserver()]
for obs in observers:
    for x in inputs: 
        obs(x)  # 收集数据
    
    # 计算量化参数
    scale, zero_point = obs.calculate_qparams()
```

### 三种观察器对比

| 观察器 | 原理 | 优点 | 缺点 | 适用场景 |
|--------|------|------|------|----------|
| **MinMaxObserver** | 记录全局最小/最大值 | 简单快速 | 对异常值敏感 | 权重量化 |
| **MovingAverageMinMaxObserver** | 使用移动平均平滑 | 更稳定 | 略复杂 | 激活值量化 ⭐ |
| **HistogramObserver** | 基于直方图 | 最精确 | 计算开销大 | 高精度需求 |

### 量化参数

观察器计算两个关键参数：

1. **scale (缩放因子)**：将浮点数映射到整数范围
   ```
   scale = (max_val - min_val) / 255
   ```

2. **zero_point (零点)**：浮点数 0 对应的整数值
   ```
   quantized_value = round(float_value / scale + zero_point)
   ```

## 常见问题

### Q1: 量化会损失多少准确率？
- 静态量化：通常 < 1%
- 如果损失 > 2%，考虑：
  - 增加校准数据量
  - 使用 QAT
  - 调整量化配置

### Q2: 量化模型为什么不支持 GPU？
- PyTorch 的 INT8 量化针对 CPU 优化
- GPU 上 FP16 混合精度通常更好

### Q3: 如何选择校准数据？
- 使用训练集或验证集的子集
- 确保数据分布有代表性
- 100-200 个批次通常足够

### Q4: 模型融合是什么？
- 将 Conv + BatchNorm + ReLU 融合成单个算子
- 减少计算开销，提高推理速度
- 示例：
  ```python
  model = quant.fuse_modules(model, [
      ['backbone.conv1', 'backbone.bn1', 'backbone.relu']
  ])
  ```

### Q5: 量化失败怎么办？
1. 确保模型在 `eval()` 模式
2. 检查量化配置是否正确
3. 尝试增加校准批次数
4. 某些自定义层可能不支持量化
