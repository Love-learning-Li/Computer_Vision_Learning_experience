## 实验理论

量化的目的是通过将FP32转化为FP8或INT8，进而降低神经网络参数所占据的存储空间，同时也加速模型的推理(在本实验中即为更快的完成图像的分类任务)。


量化分为线性映射和非线性映射，线性映射如下式所示：

$$
\begin{aligned}
r &= S(q - Z) \\
q &= \operatorname{clamp}\left(\text { round }(\frac{r}{S} - Z), q_{\min }, q_{\max }\right) \\
S &= \frac{r_{max} - r_{min}}{q_{max} - q_{min}} \\
\end{aligned}
$$

其中r表示real，即量化前的值；q表示quantized，即量化后的值；Z表示zero，即量化零点；S表示scale，即量化缩放因子。

其中零点Z用于区分对称映射和非对称映射。例如Relu激活函数，它仅在正数有分布，并非完全对称的分布，因此会设定Z不等于0来实现非对称映射。对应的有，若想实现对称映射，则可将Z设为0.

量化后的神经网络模型整体数据传输流程如下：

```txt
数据流:       Input   -> Quantize(Min-Max量化策略) -> QuantizedRelu -> Dequantize -> Output(FP32)
数据类型:      FP32   ->         INT8             ->     INT8       ->  FP32     ->  FP32 
数据大小: 32Bit,4Byte ->      8Bit,1Byte         -> 8Bit,1Byte    -> 32Bit,4Byte -> 32Bit,4Byte 
```


## 代码实践

注意，因为我们在量化的过程中，涉及到输入参数类型由**FP32**转到**INT8**，若采用Pytorch原生的静态量化，我们需要在模型本身的搭建过程中需进行如下修改：

```python
class ResNetClassifier(nn.Module):
    """完整的 ResNet 分类器"""
    def __init__(self, block, layers, num_classes=100,
                in_channels=3, img_size=32):  # 为 CIFAR-100 设计
        super().__init__()
        self.backbone = ResNetBackbone(block, layers, in_channels)
        
        # 针对小图像的调整（如 CIFAR-10/100）
        if img_size <= 32:
            self.backbone.conv1 = nn.Conv2d(in_channels, 64, kernel_size=3, 
                                          stride=1, padding=1, bias=False)
            self.backbone.maxpool = nn.Identity()  # 移除 maxpool

        self.fc = nn.Linear(512 * block.expansion, num_classes)

        # ❗ 添加量化桩——让Pytorch的工具识别需要量化
        self.quant = torch.quantization.QuantStub()
        self.dequant = torch.quantization.DeQuantStub()

    def forward(self, x):
        # ❗ 输入量化
        x = self.quant(x)
        x = self.backbone(x)  # (B, 512*expansion)
        x = self.fc(x)        # (B, num_classes)
        # ❗ 输出反量化
        x = self.dequant(x)
        return x
```

但静态量化后的模型权重文件load与测试十分繁琐，因此我们采用最新的torchAO来实现模型权重的压缩，来加快推理。

### 测试代码


```python
# Performance_Test.py
# 通过load已量化的模型权重来测试模型完成每epoch的图像分类任务的准确率与延迟时间
import torch
import torchvision.datasets as datasets
import torch.nn as nn
import torchvision
import torchvision.transforms as transforms
import torch.utils.data as data_utils
from torch.utils.data import DataLoader
from torch.optim.lr_scheduler import CosineAnnealingLR
from Resnet4CIFAR100 import resnet18, resnet34, resnet50, resnet101
import time
from torchao.quantization import quantize_
from torchao.quantization.quant_api import int8_dynamic_activation_int8_weight

# ----------------------------
# 1. CIAFR-100数据集加载
# ----------------------------
CIFAR100_TRAIN_MEAN = (0.507075, 0.486548, 0.440917)
CIFAR100_TRAIN_STD  = (0.267334, 0.256438, 0.276150)

def get_cifar100_loaders(batch_size):
    transform_test = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize(CIFAR100_TRAIN_MEAN, CIFAR100_TRAIN_STD),
    ])

    test_dataset = torchvision.datasets.CIFAR100(root='./data', train=False,
                                           download=True, transform=transform_test)
    test_loader = DataLoader(test_dataset, batch_size=batch_size, shuffle=True,
                            num_workers=10, pin_memory=True)

    return test_loader

# ----------------------------
# 2. Evaluation
# ----------------------------

def evaluate(model, loader, criterion, device):
    model.eval()
    total_loss = 0
    correct = 0
    total = 0
    start_time = time.time()
    with torch.no_grad():
        for inputs, targets in loader:
            inputs, targets = inputs.to(device), targets.to(device)
            outputs = model(inputs)
            _, predicted = outputs.max(1)
            total += targets.size(0)
            correct += predicted.eq(targets).sum().item()
    end_time = time.time()
    once_delay_time = end_time - start_time
    return 100. * correct / total, once_delay_time


# ----------------------------
# 3. Main Training Loop
# ----------------------------
def main():
    # device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    device = torch.device("cpu")
    # 临时修改模型为CPU，以验证量化前后都在CPU上模型的性能
    print(f"Using device: {device}")

    # Hyperparameters
    batch_size = 128
    epochs = 5
    lr = 0.01

    # Data
    testloader = get_cifar100_loaders(batch_size)

    # Model
    model = resnet34()
    model.eval()
    quantize_(model, int8_dynamic_activation_int8_weight())

    # 4. 加载量化权重
    state_dict = torch.load("resnet34_cifar100_int8.pth", map_location="cpu")
    model.load_state_dict(state_dict)

    # Loss & Optimizer
    criterion = nn.CrossEntropyLoss(label_smoothing=0.1)

    fast_delay_time = 999.9
    slow_delay_time = 0.0
    once_delay_time = 0.0
    all_delay_time = 0.0
    avarge_delay_time = 0.0
    for epoch in range(epochs):
        test_acc, once_delay_time = evaluate(model, testloader, criterion, device)
        all_delay_time += once_delay_time
        avarge_delay_time = all_delay_time / (epoch + 1)

        print(f"Epoch [{epoch + 1}/{epochs}] "
              f"Test Once Delay: {once_delay_time:.4f}s,
               Avarge Delay: {avarge_delay_time:.4f}s | ")

        
        if once_delay_time < fast_delay_time:
            fast_delay_time = once_delay_time
        
        if once_delay_time > slow_delay_time:
            slow_delay_time = once_delay_time

    print(f"🎉 Training finished.\n")
    print(f"test accuracy: {test_acc:.2f}%")
    print(f"most fast delay time : {fast_delay_time:.4f}s")
    print(f"most slow delay time: {slow_delay_time:.4f}s")
    print(f"avarge delay time: {avarge_delay_time:.4f}s")



if __name__ == "__main__":
    main()
```

## 总结如下

| 模型类型 | 权重文件大小 | 运行设备 | 测试准确率 (%) | 最快延迟 (s) | 最慢延迟 (s) | 平均延迟 (s) |
|----------|---------------|----------|------------------|----------------|----------------|----------------|
| FP32     | 85.46 MB      | GPU      | 70.64            | 1.1939         | 1.8001         | 1.3097         |
| FP32     | 85.46 MB      | CPU      | 70.63            | 298.1910       | 317.2498       | 306.4379       |
| INT8 (torchao) | 85.30 MB  | CPU      | 70.59            | 40.5403        | 43.8527        | 42.5230        |
| INT8 (Post-Training Quantization) | 21.73 MB  | CPU      | 69.48             |         |         |        |

> **观察结论**：
> - INT8 量化在 CPU 上相比 FP32 **提速约 7.2 倍**（306s → 42s），且精度几乎无损（70.63% → 70.59%）。
> - GPU 运行 FP32 仍是**最快选择**（平均 1.31s），比 CPU 上的 INT8 快约 **32 倍**。
> - 权重文件大小在量化前后基本不变（因 torchAO 保存机制，torchAO也称为动态量化），若采用Pytorch原生的静态量化(Post-Training Quantization, PTQ)方案，则其性能验证更为繁琐，故本文采用torchAO来实现。
